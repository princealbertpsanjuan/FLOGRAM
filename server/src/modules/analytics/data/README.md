# AFINN-165 lexicon

`afinn-165.json` is the AFINN-165 English sentiment lexicon by Finn Årup Nielsen
(3,382 words and phrases scored from -5 to +5), converted from
`AFINN-en-165.txt` in https://github.com/fnielsen/afinn.

License: Open Database License (ODbL) v1.0 — see the source repository.
Cite: F. Å. Nielsen, "A new ANEW: Evaluation of a word list for sentiment
analysis in microblogs", 2011.

`filipino-extension.json` is a small FLOGRAM-specific list of common Filipino /
Taglish and flower-delivery review words (e.g. "wilted", "lanta") scored on the same -5..+5 scale, used in addition to AFINN.
